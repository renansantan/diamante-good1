# Diamante Good — site demonstrativo

## Imagens
Coloque suas fotos na pasta `images` com estes nomes:
- hero.jpg — imagem principal
- loja.jpg — fachada/interior
- oculos-1.jpg
- oculos-2.jpg
- oculos-3.jpg

Pode usar JPG, PNG ou WEBP, mas se mudar o nome/extensão, altere também o `src` correspondente no `index.html`.

## WhatsApp
No `index.html`, substitua `55SEUWHATSAPP` pelo número da loja, somente números.
Exemplo: `5581999999999`.

## GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e a pasta `images`.
3. Vá em Settings → Pages.
4. Em Source, selecione Deploy from a branch.
5. Escolha `main` e `/ (root)`.
6. Salve e aguarde a publicação.
